# 항해 시간 시뮬레이터 UI 외형 검증

**한계:** 두 이미지 모두 축소돼 보였습니다. 데스크톱은 619px, 모바일은 113px 폭입니다. 그래서 작은 글자의 정확한 내용, 겹침 여부, 대비 수치는 확정하지 못했습니다. 아래 판정은 레이아웃과 구조 기준입니다. 모바일은 구조만 봤고 세부 판정은 못 했습니다. 크롭해서 다시 보면 더 정확하게 확인할 수 있습니다.

| 항목 | 판정 | 근거 |
|---|---|---|
| 1) 정보 위계·가독성 | 개선 | KPI 6개와 밸런스 체크(6/0 통과)가 상단에 있어 결론을 먼저 읽을 수 있습니다. 반면 라벨, 보조 설명, 표 본문이 거의 같은 작은 글자 크기라 위계가 약합니다. 행성별 도착표는 45행에 열이 14개 안팎이라 가장 조밀합니다. KPI 값은 크지만 하단 설명 줄은 흐립니다. |
| 2) 차트 축·라벨 겹침/잘림 | 개선 | 구간별 소요 시간 차트에서 범례 항목이 한 줄에 몰려 마지막 항목이 잘린 것처럼 보입니다. 같은 차트의 "첫 번째 목표 24시간 40분" 주석은 우측 막대와 가까워 겹칠 위험이 있습니다. 누적 거리 차트의 로그축은 눈금이 촘촘하고, 행성 라벨(프록시마 b 등)이 점과 가깝습니다. 순항 속도 차트는 계단형이라 읽기 쉽습니다. 확대 확인이 필요합니다. |
| 3) 표 잘림·가로 넘침 | 개선 | 데스크톱에서는 행성 표가 컨테이너 안에 들어와 넘침이 보이지 않습니다. 일부 셀의 행성명은 2줄로 줄바꿈되고(HD 209458 b 등) 우측 끝 열(판정 배지)은 폭이 빠듯합니다. 모델 비교 표는 정상으로 보입니다. |
| 4) 모바일 레이아웃 | 확정 불가 (개선 의심) | 폭 390px 안에서 KPI, 밸런스 체크, 차트가 1열로 쌓여 있고 이미지 가로폭은 정상이라, 페이지 전체의 가로 스크롤은 없어 보입니다. 전체 높이가 약 6,900px로 매우 깁니다. 설정 패널이 상단에 있는지 하단에 있는지, 행성 표가 가로 스크롤인지 열 생략인지는 이 해상도로 판단할 수 없습니다. 터치 크기(슬라이더, 버튼 ≥44px)도 확인하지 못했습니다. |
| 5) 색 대비 | 개선 | 어두운 배경에 회청색 보조 텍스트와 작은 캡션이 많습니다. 설정 패널 힌트, 표 부제(영문 행성명), 차트 범례가 4.5:1에 못 미칠 가능성이 큽니다. PASS 배지(녹색)와 막대 색(파랑/보라/주황/분홍)은 구분이 잘 됩니다. 단, 구간 색을 색으로만 구분하고 있습니다. |
| 6) 밸런스 도구로서 빠진 정보 | 개선 | 현재 밸런스 체크는 PASS/FAIL만 보여 주고, 기준값 대비 얼마나 여유가 있는지는 안 보입니다. 또 설정을 바꿨을 때 이전 값(또는 기본 프리셋)과의 차이가 KPI에 없습니다. 목표 총 소요 시간, 구간 간 체감 격차(연속 구간 비율), 하루 몇 세션이 필요한지 같은 지표도 없습니다. |

## 개선 가치가 큰 수정 3개

1. **보조 텍스트 대비와 최소 글자 크기 상향** (항목 1, 5)
   - 캡션, 힌트, 표 부제, 범례의 색을 현재보다 밝게 올립니다. 예: `color: #9fb0c8` 이상, 배경 대비 4.5:1 이상.
   - `font-size`는 12px 미만 요소를 모두 12~13px로 올립니다.
   - 표 셀은 `font-variant-numeric: tabular-nums`로 숫자 열 정렬을 맞춥니다.

2. **구간별 소요 시간 차트의 범례와 주석 정리** (항목 2)
   - 범례 컨테이너에 `flex-wrap: wrap; gap: 6px 14px`를 주고 `overflow: visible`로 합니다. 잘림을 막고 모바일에서는 2줄로 접히게 합니다.
   - "첫 번째 목표 24시간 40분" 주석은 `text-anchor: end`와 `y` 오프셋(-8px)으로 막대 위로 띄웁니다. 우측 경계에서 `x`를 클램프합니다.
   - 구간 색 외에 구간 이름 라벨을 x축에 병기해, 색만으로 구분하지 않게 합니다.

3. **행성별 도착표의 모바일 대응** (항목 3, 4)
   - 표 래퍼에 `overflow-x: auto; -webkit-overflow-scrolling: touch`를 줍니다.
   - 첫 열(행성명)은 `position: sticky; left: 0; background: var(--panel)`로 고정합니다.
   - `@media (max-width: 640px)`에서 부가 열(누적 집중, 순항 속도 등)은 `display: none`으로 숨기거나 행 확장 방식으로 바꿉니다.
   - 모바일 슬라이더와 버튼은 `min-height: 44px`로 맞춥니다.

원하시면 두 이미지를 구역별로 크롭해 다시 보고 위 판정을 확정해 드리겠습니다. 크롭본은 `/tmp`에 저장하고 원본은 건드리지 않습니다.
