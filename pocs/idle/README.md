# 우주선 대기 PoC

요구사항: [docs/prompts/POC_IDLE_UI.md](../../docs/prompts/POC_IDLE_UI.md) · 배치 참고: [01-main-r2.png](../../docs/screens/drafts/v2/01-main-r2.png) · 셸: [pocs/mockup](../mockup)

메인 화면에서 우주선이 대기하는 장면만 구현했다. 배경과 행성은 들어올 때마다 무작위로 고르고, 우주선은 화면 정중앙에서 노즈를 위로 향한 채 천천히 떠다닌다. 데스크톱에서는 아이폰 목업에 넣어 보여주고, 모바일에서는 전체 화면으로 보여준다. 이 부분은 pocs/mockup과 같다.

## 배포본

- https://claude.ai/artifact/LD3x8Dhz7Fp9RW6Weim2oe (비공개: 공유 메뉴에서 공유해야 다른 사람이 열 수 있다)
- 휴대폰으로 열면 전체 화면으로, 데스크톱에서는 목업으로 보인다. **행성 이름을 탭**하면(데스크톱에서는 `R` 키도 가능) 배경과 행성을 다시 뽑는다.
- Artifact에서는 쿼리 파라미터가 전달되지 않으므로 `?planet=`, `?bg=`, `?frame=`은 로컬 서버에서만 쓸 수 있다. Pretendard는 Artifact CSP 때문에 불러오지 않으므로 시스템 한글 글꼴로 보인다.
- 다시 배포할 때: `python3 scripts/build-deploy.py <폴더>`로 사본을 만든 뒤 그 폴더를 Artifact로 게시한다(같은 URL로 갱신).

## 실행

```bash
cd pocs/idle
PORT=5195 npm run dev        # http://127.0.0.1:5195/
npm run dev:https            # 휴대폰 실기기 확인용 (https://<LAN IP>:5174)
```

| 파라미터 · 키 | 뜻 |
| --- | --- |
| 새로 고침 · `R` 키 · 행성 이름 탭 | 배경과 행성을 다시 고른다. 직전과 같은 것은 고르지 않는다 |
| `?planet=<id>` | 행성을 고정한다. id 예: `earth` `mars` `jupiter` `trappist-1e` (`assets/manifest.json` 참고) |
| `?bg=<파일 이름>` | 배경을 고정한다. 확장자를 뺀 파일 이름을 쓴다. 예: `lagoon-nebula-eso0936a` |
| `?frame=0\|1` | 전체 화면 / 아이폰 목업 (기본값: 모바일이면 전체 화면) |
| `?sb=1` | 전체 화면에서도 가상 상태 표시줄을 그린다(캡처용) |

## 장면 배치

시안(1179×2556)에서 잰 비율을 컨테이너 쿼리 단위(`cqw`/`cqh`)로 옮겼다. 그래서 목업, 실기기, 가로 화면 어디서나 같은 비율로 배치된다.

| 요소 | 값 | 근거 |
| --- | --- | --- |
| 우주선 중심 | 화면 (50%, 50%) | 요구사항: 정중앙 |
| 우주선 폭 | 화면 폭의 26% (가로 화면에서는 높이의 12.5%로 제한, 72–150px) | 시안 238/923 ≈ 26% |
| 행성 지평선 | 화면 높이의 34% (가로 화면에서는 우주선 윗변보다 4% 위로 제한) | 시안에서 지평선은 우주선 중심보다 화면 높이의 약 13.5% 위에 있다. 외형 검증에서 '더 올리라'는 지적을 받아 36.5%에서 올렸다 |
| 행성 지름 | `max(250cqw, 120cqh)` | 시안처럼 지평선이 완만하게 휜다. 가로 화면에서도 하단을 덮는다 |

- **배경**: 우주 사진을 `brightness(.5)`로 어둡게 누르고, 위아래에 비네트를 깐다. 성운처럼 화려한 사진이 뽑혀도 글자와 우주선이 묻히지 않는다. 90초 주기로 아주 느리게 흐른다.
- **행성**: 대기광 색은 행성마다 다르다. 원반 윗부분의 평균색으로 정하며, 지구만 푸른색으로 직접 지정했다. 지평선 아래는 화면 기준 그라데이션으로 점점 어두워진다. 원반 기준 %를 쓰면 화면비에 따라 어두워지는 위치가 크게 달라지기 때문이다.
- **두둥실 움직임**: 세 동작의 주기를 일부러 다르게 했다. 그래서 같은 동작이 반복되는 느낌이 덜하다.
  - 위아래로 ±7px 이동(5.6초)
  - ±1.4° 기울기(8.4초)
  - 엔진 분사광: 떠오를 때 밝아지는 숨쉬기(5.6초)

  `prefers-reduced-motion`이 켜져 있으면 떠다니기, 기울기, 배경 흐름, 등장 이동을 모두 끄고 정지 장면으로 보여준다.
- **전환**: 배경과 행성 이미지를 디코드까지 끝낸 뒤 장면을 페이드인한다. 이때 행성이 살짝 떠오른다. 그래서 이미지가 늦게 뜨며 깜빡이는 일이 없다.
  - 연타하면 마지막 요청만 반영된다(요청 토큰 비교). 키 자동 반복은 무시한다.
  - 이미지 하나라도 로드에 실패하면 이전 장면을 유지한다.

## 에셋

```bash
python3 scripts/build-assets.py   # Pillow 필요. assets/space, assets/planets, assets/manifest.json 을 다시 만든다
```

- `assets/space/`: `docs/design/refs/space/images` 48장 전부. 긴 변을 1400px로 줄였다(JPEG q78, 약 12MB).
- `assets/planets/`: `docs/design/refs/planet/images` 가운데 원반 전체가 검은 배경에 보이는 10개만 원형 투명 WebP(1024px)로 잘랐다.
  - 대상: 지구, 금성, 화성, 수성, 목성, 천왕성, 해왕성, 명왕성, 트라피스트-1 e·f
  - 나머지 외계행성 상상도는 항성이나 배경이 함께 그려져 있어 원형으로 자를 수 없으므로 뺐다.
  - 원 검출: 밝기 마스크의 경계점에 최소제곱으로 원을 맞춘다. 맞춘 원보다 안쪽에 있는 점은 버리고 다시 맞춘다. 밤 쪽이 어두운 행성도 중심이 밀리지 않는다.
  - 금성, 수성, 트라피스트 행성은 위상 때문에 한쪽이 어둡다. 화면에는 윗부분만 보이므로 밝은 면이 위로 오게 돌렸다.
  - 목성은 극 쪽이 납작해서 극반지름에 맞췄다.
- `assets/rocket.png`: `pocs/clone/assets/gen/rocket-front.png`(Codex CLI 생성, 정면 로켓, 노즈가 위를 향함)
- 배경과 행성 이미지의 출처와 라이선스는 각 레퍼런스 폴더의 README를 따른다. 우주 배경은 CC BY 4.0이므로 크레딧 표기가 필요하다.

## 검증

```bash
node scripts/shots.mjs <출력 폴더> [http://127.0.0.1:5195/]
```

헤드리스 Chrome(CDP)으로 다음 화면을 캡처한다:
- 393×852 @3x: 시안과 같은 크기. 지구, 화성, 목성, 트라피스트, 무작위
- 375×667
- 852×393 가로
- 1440×900 목업

캡처와 함께 다음 값을 잰다:
- 우주선 중심 좌표와 지평선 위치
- 6초 동안 잰 떠다니는 진폭
- `R` 키로 다시 뽑은 결과

측정 결과(393×852):
- 우주선 중심 (0.501, 0.492)
- 지평선 0.34
- 떠다니는 진폭 14.6px, 반주기 약 2.8초
- `R` 키를 누르면 배경과 행성이 함께 바뀜

### 멀티에이전트 검증 (docs/prompts/POC_BASE.md)

| 역할 | 에이전트 | 결과 |
| --- | --- | --- |
| 구현, 비주얼 정리, 에셋 가공 | Claude Opus 5.5 | 이 디렉터리 |
| 우주선 이미지 | Codex CLI | `pocs/clone`에서 생성한 정면 로켓을 재사용. 이번에는 새로 생성하지 않음 |
| 외형 검증 | Claude CLI (Sonnet 5.5): 시안과 캡처 8장 비교 | 아래 지적을 반영함: 인사말 대비, 밝은 성운 배경, 날카로운 행성 테두리와 약한 대기광, 지평선 높이, 가로 화면에서 노즈가 지평선에 걸리는 문제 |
| 코드 리뷰 | Codex CLI (gpt-6.2-sol) | 아래 지적을 반영함: 이미지 실패 시 장면 처리, `R` 자동 반복, rAF 토큰 검사, 동작 줄이기, 모바일에서 목업 PNG 요청, 캡처 스크립트 준비 검증, 원 검출 예외 처리, 캡션 대비 |

반영하지 않은 지적:
- **iOS 16.1 이하 호환(`cqw`/`cqh`, `color-mix`)**: 이 PoC는 최신 iOS를 대상으로 한다. 구형 기기를 지원해야 하면 `@supports` 대체값이 필요하다.
- **원 바깥의 밝은 물체를 경계로 오인하는 문제**: 현재 10개 행성은 캡처로 직접 확인했다. 행성을 추가할 때는 결과를 눈으로 확인해야 한다.
- **HTTPS 인증서 갱신**: `serve.mjs`는 pocs/mockup의 코드를 그대로 쓴다.
