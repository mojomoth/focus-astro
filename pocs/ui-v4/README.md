# Focus Astro UI v4 (UI 컴포넌트 전용)

`pocs/clone`(clone-v10)을 바탕으로 배경·우주선·행성 아트를 모두 걷어 내고, UI 컴포넌트(텍스트·슬라이드·버튼·패널)만 검정 바탕에 남긴 버전이다. 캡처 결과는 `docs/screens/drafts/v4/`에 있다.

```bash
cd pocs/ui-v4 && PORT=5191 npm run dev
node scripts/shots.mjs ../../docs/screens/drafts/v4 http://127.0.0.1:5191/
```

clone에서 바꾼 점:

- 메인: 좌상단에 앱 타이틀 `FOCUS ASTRO`(Pretendard 900)를 넣고, 인사말('좋은 저녁입니다!')을 뺐다. 야간 지구, 우주선, 위치 핀도 없앴다.
- 이륙: 궤도 지도(지구, 행성, 경로선, 우주선)를 없앴다. 슬라이드 아래 카드에 행성 이미지와 정보를 넣었다. 정보는 이름, 영문명, 분류, 한 줄 설명, 거리, 집중 시간이다.
  - 데이터와 이미지는 `docs/design/refs/planet/`에서 가져왔다(`assets/thumbs/`는 320px 정사각 크롭).
  - 목적지: 금성 30분 → 화성 1시간 → 수성 → 목성 → 토성 → 천왕성 → 해왕성 3시간 30분 → 프록시마 b 4시간 15분 → 바너드별 b 6시간
  - 외계행성은 README 규칙(1광년 = 집중 1시간)을 따른다. 태양계 행성은 30분 간격의 게임 값이다.
- 출항(집중·휴식): 성운, 속도선, 우주선을 없앴다. 다른 우주선은 이름·거리 태그만 남겼다.
