## 화면

| 화면 | 스케치 배치 | 구현 |
| --- | --- | --- |
| 메인 | 좌상단 현재 위치 텍스트, 중앙 우주선, 우하단 '이륙' 버튼 | 야간 지구(서울 핀), 대기 중인 우주선(진동 + 분사광), 탭 + 이륙 FAB |
| 이륙 | 위쪽 우주선·행성, 거리 슬라이드, 행성 3개, 버튼 | 궤도 지도(지구 → 선택 행성 경로선), 눈금자 드래그(목적지에 스냅), 카드 스와이프, 셔플, '출항하기' |
| 출항 | 오른쪽으로 날아가는 우주선, 속도선, 다른 우주선 | 흐르는 성운과 속도선, 엔진 플레어, 함께 항해하는 우주선 2척, 앞선 우주선 수, 진행 카드, 중단 확인 |
| 휴식 | 정지한 우주선 | 성운·속도선·플레어 정지, 원형 일시정지 손잡이, '휴식 건너뛰기' |

포모도로는 집중 30분, 휴식 10분이다. 목적지 시간을 30분 단위로 나눠 세트 수를 정한다(화성 1시간 = 2세트). 완주하면 메인의 현재 위치와 '오늘 집중' 시간이 바뀐다.

목적지 시간(금성 15분 … 세레스 2시간 30분)은 시안의 카드 순서(달 30분, 화성 1시간, 목성 1시간 30분)에 맞춘 게임 값이다. AU는 실제 궤도 간격이지만, 세레스는 시간 순서와 AU 순서가 맞지 않는다.

## 유사도 루프 (gauntlet-loop 방식)

```bash
node scripts/shots.mjs ../../docs/screens/drafts/clone-vN          # 393×852 @3x = 1179×2556 캡처 (CDP)
uv run --with pillow --with numpy --with scikit-image \
  python scripts/compare.py ../../docs/screens/drafts/clone-vN [시안 폴더]
```

`compare.py`의 지표:

- **ssim**: 흑백 구조 유사도
- **edge**: 윤곽 맵 SSIM으로 본 배치 일치도
- **color**: Lab 히스토그램 교차로 본 톤 일치도
- **score** = 0.4·ssim + 0.35·edge + 0.25·color

상태 표시줄이 없는 시안이 섞여 있어 세로 오프셋을 ±70px 범위에서 찾아 보정한다. 결과 이미지는 `clone-vN/compare/`에 저장된다.

gauntlet의 기준은 점수가 아니다. **블라인드 비평가가 우리 화면을 고르는가**로 판단한다. Claude CLI(Sonnet)에 시안과 클론을 라벨 없이 A/B로 보여 준다. 비평가가 A 위치를 더 자주 고르는 편향이 보여서, 라운드 7부터는 같은 쌍을 AB와 BA **두 순서로 판정**했다.

| 라운드 | 주요 변경 | score 평균 | 블라인드 판정 (클론 선택) |
| --- | --- | --- | --- |
| v1 | 첫 구현(캡처 폭 버그 있음) | 0.415 | — |
| v2 | CDP 캡처, 최신 시안 좌표 반영 | 0.487 | — |
| v3 | 시안 고정 스냅숏, 독·헤더 위치 | 0.499 | — |
| v4 | Codex 배경(은하수, 청록 성운) | **0.566** | 3/4 (단일 순서) |
| v5 | 엔진 플레어, 속도선, 진행 마커 | 0.550 | 3/4 |
| v7 | 지구 림 제거, 헤일로, 카드 톤 | 0.535 | 6/8 (양순서) |
| v10 | 휴식 프로스트 카드, 분사광, 별 레이어 | 0.524 | **6/8**: 집중 2/2 · 휴식 2/2 · 메인 1/2 · 이륙 1/2 |

비평가 지적을 반영할수록 픽셀 점수는 조금 떨어졌다. 예를 들어 성운을 어둡게 하자 비평 결과는 좋아졌지만 color 지표는 낮아졌다. 메인과 이륙은 화면을 바꾸지 않아도 라운드마다 2/2와 1/2를 오갔고, 남은 지적도 순서에 따라 서로 반대였다. 그래서 비평가 노이즈 범위에 들어왔다고 보고 루프를 멈췄다.
