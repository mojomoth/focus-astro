# 우주선 항해 PoC

요구사항: `docs/POC_VOYAGE.md` (운영 규칙: `docs/POC_BASE.md`)

## 실행

```bash
cd pocs/voyage && python3 -m http.server 5173
# http://127.0.0.1:5173/        (노즐 위치·파티클 수 확인: ?debug)
```

- `pocs/mockup`의 목업 셸을 적용했다. 데스크톱에서는 아이폰 프레임 안(논리 390×891 화면)에 표시하고, 모바일(터치 입력)에서는 프레임 없이 전체 화면으로 표시한다.
- `?frame=1`은 목업 표시를 강제하고, `?frame=0`은 전체 화면을 강제한다.
- 목업 셸은 `index.html`의 셸 CSS와 `shell.js`(배율 계산, 가상 상태 표시줄 시계)로 구성된다. 항해 화면은 `#app` 컨테이너를 기준(`cqw`, `cqh`)으로 크기를 잡는다. 캔버스도 창이 아니라 `#app` 크기와 목업 배율에 맞춰 해상도를 정한다.

## 구성

| 요구사항 | 구현 |
| --- | --- |
| 배경 랜덤, 10초마다 전환 | `assets/bg/`(refs/space 중 짧은 변 1080px 이상에서 랜덤 10장, 런타임에서도 1080px 미만은 건너뜀). 셔플 순서로 하나씩 꺼내고, 직전 이미지는 반복하지 않음. 다음 이미지를 미리 불러 둠 |
| Fade In / Fade Out | 두 레이어의 opacity를 5초 동안 크로스페이드(ease-in-out). 각 배경은 오른쪽에서 왼쪽으로 3%씩 천천히 흐름 |
| 미세 먼지 파티클(우→좌) | `#dust` 캔버스. 깊이(z)에 따라 속도·크기·투명도가 달라짐. 가까운 먼지는 짧은 꼬리를 그리고, 우주선 앞쪽 레이어에 둠 |
| 우주선 정중앙 | `assets/ship.png`(Codex CLI 생성, 투명 PNG). 위아래로 미세하게 흔들림. 크기는 `--ship-scale: .25`(이전 대비 1/4)이며, 세로 화면 기준 화면 폭의 15.5%(390pt 화면에서 약 60pt)이다 |
| 좌측 연기, 화면 밖까지 | `#smoke` 캔버스. 노즐에서 초당 90개를 내보내고, 수명은 3.2~5.2초. 감쇠와 난류를 줌. 노즐에는 청백 글로우를 가산 합성으로 그림. 로드할 때 5초 분량을 미리 계산해 처음부터 트레일이 화면 밖까지 이어짐 |
| 하단 집중/휴식 토글 | `.mode-toggle`(세그먼트 버튼, `aria-pressed`). 내부의 속도값 `throttle`(0~1)이 약 2초에 걸쳐 목표값으로 감속하거나 가속한다. **휴식**이면 먼지의 우→좌 이동이 멈추고, 엔진이 꺼져 새 연기와 노즐 빛이 나오지 않는다. 남은 연기는 그 자리에서 흩어지고, 배경 흐름과 10초 배경 전환 타이머도 멈춘다. 우주선은 제자리에서 둥실거리기만 한다. **집중**이면 모두 다시 출발한다 |

튜닝 값은 `voyage.js`의 `CONFIG`에 있다. 노즐 좌표(`nozzle`)는 `ship.png` 기준 비율이다.

## 멀티에이전트 작업 기록

- **이미지 생성:** Codex CLI(`gpt-6.2-sol`). 시안 `docs/screens/drafts/v1/03-flight-focus.png`를 첨부해 측면 우주선 스프라이트를 생성함. 알파 검증, 4% 여백 크롭, 노즐 y좌표 측정까지 맡음

- **외형 검증:** Claude CLI(`claude-sonnet-5-5`). `verify/*-1.jpeg` 스크린샷을 검증함. 결과는 `verify/claude-review.md`. 검증에서 나온 제안(연기 톤과 형태, 모바일 톤다운, 먼지 가시성, 우주선 크기)을 반영한 결과는 `verify/*-2.jpeg`
