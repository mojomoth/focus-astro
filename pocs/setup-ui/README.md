# Focus Astro · 설정(이륙) UI PoC

목적지 설정 화면의 인터페이스 컴포넌트(눈금자, 행성 카드 슬라이드, 출항 버튼)를 확인하는 PoC다.

- 디자인: `docs/screens/drafts/v4/02-takeoff.png`
- 슬라이드 움직임: `docs/design/refs/mov/슬라이드인터페이스.mov`를 프레임 단위로 분석해 재현했다(`scroller.js`).
- 카드 데이터: `docs/design/refs/planet/README.md`의 행성 43개. 이름, 거리, 이미지를 표시한다. 지구(출발점)와 이미지가 없는 SWEEPS-11 b는 제외했다.

```bash
cd pocs/setup-ui
npm run data                     # README → data/planets.js + assets/thumbs/ (다시 만들 때만)
PORT=5192 npm run dev            # http://localhost:5192  (?frame=0 전체 화면 · ?debug=1 오프셋/속도 표시 · ?sel=0 시작 카드)
node scripts/shots.mjs <outDir>  # 393×852 @3x 캡처
node scripts/motion-test.mjs     # 헤드리스 Chrome에서 플링을 재생해 영상 측정값과 비교
```

## 영상 분석 → 구현값

영상(296×640, 60fps, 7.9초)의 카드 줄을 프레임마다 상호상관으로 추적했다(1px = 1.328pt).

| 항목 | 영상 | 구현 (`motion-test` 결과) |
| --- | --- | --- |
| 스냅 | 없음. 놓은 자리에서 관성으로 멈춤 | 동일 |
| 관성 속도 반감기 | 0.33–0.40초 (iOS 기본 감속 0.998/ms) | 0.349초 |
| 끝을 넘는 거리 | 경계 통과 속도 약 0.8pt/ms일 때 약 28pt | 통과 속도에 비례: 0.67pt/ms → 23pt, 0.71pt/ms → 28pt |
| 경계 통과 → 정점 | 0.08–0.10초 | 0.101초 |
| 정점 → 복귀 | 0.35–0.40초, 임계 감쇠 | 0.383초 |
| 움직이는 중 터치 | 즉시 멈추고, 그 탭은 선택하지 않음 | 동일 |
| 눌림 하이라이트 | 손가락이 머문 카드가 파랗게 변하고, 드래그를 시작하면 페이드 아웃 | 동일(70ms 지연 후 켜고 0.28초 동안 페이드) |
| 선택 카드 | 스크롤해도 흰 카드는 그대로 | 동일. 탭해야 선택이 바뀜 |
| 드래그로 끝을 넘김 | 러버밴드 저항 | iOS 공식 `(1 − 1/(x·0.55/D + 1))·D` |

영상에 없어서 따로 정한 동작:

- 정지 상태에서 카드를 탭하면 선택하고, 그 카드를 같은 임계 감쇠 스프링으로 가운데로 옮긴다.
- 눈금자는 목적지마다 큰 눈금 하나를 128px 간격으로 둔다. 시안의 30분 / 1시간 / 1시간 30분 간격과 같다. 눈금자를 끌면 가장 가까운 목적지가 실시간으로 선택되고 카드 줄이 따라온다.
- 집중 시간은 태양계 행성이 30분 간격 게임 값(ui-v4와 같음)이고, 외계행성은 README 규칙(1광년 = 집중 1시간)을 따른다.
- 배지 코드(VEN, MRS, PXB …)는 README에 없어서 `scripts/build-data.mjs`에서 정했다.

## 파일

- `scroller.js`: 슬라이드 물리 엔진(관성, 경계 급감속, 복귀 스프링, 러버밴드, 잡기/탭 판정, 휠)
- `app.js`: 카드와 눈금자 렌더링, 선택, 헤더 버튼
- `data/planets.js`: 자동 생성 데이터
- `scripts/motion-test.mjs`: 움직임 회귀 테스트
