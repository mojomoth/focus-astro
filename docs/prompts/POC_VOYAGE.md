# 우주선 항해 PoC

- @POC_BASE.md

- 필요 에셋: docs/design/refs/space/images/ 에 아무거나 랜덤
- 10초마다 배경이 전환 
  - 배경은 Fade In / Fade Out 으로 부드럽게 전환
  - 전환은 5초가 걸린다.
- 미세한 먼지같은 투명한 파티클을 표시 
  - 파티클이 우에서 좌로 이동하면서 움직이는 느낌
- 우주선
  - 우주선은 정 중앙에 위치
  - 우주선 좌측으로 연기 파티클 이펙트를 화면 밖까지 길게 표현

- 하단에 간단하게 집중/휴식 전환 토글 버튼 표시
  - 집중 상태에서는 우주선이 움직인다
  - 휴식 상태에서는 우주선이 멈춘다.

- 배경

  - 해상도가 낮은 배경은 사용하지 않는다.
