# Focus Astro

- 로그라이크형 집중 앱 
- 우주선이 지구를 출발해서 집중 시간동안 항해를 한다.
- 컨셉설명: @CONCEPT.md

## 집중앱 동작 방법

메인화면에서는 내 위치가 표시되는데 시작 지점은 '지구'에서 시작된다. 이륙 버튼을 클릭하면 우주선이 포커스 아웃되면서 이륙 준비중인 상태로 표시한다. 슬라이드로 목표지점을 설정한다. 슬라이드 동작을 하면 목표 지점에 따른 행성들을 볼 수 있다. '출항'버튼을 클릭하면 우주선이 출항되며 집중 상태로 전환한다. 집중은 30분 집중, 10분 휴식으로 반복 진행한다. 출항 중일때는 나보다 더 많은 거리로 도달한 우주선의 숫자들을 보여준다. 해당 지점을 통과할때 해당 우주선을 지나치는 연출이 필요하다. 앱을 종료하거나 백그라운드로 가는 등 포커스 아웃이되면 출항 실패가 되어 다시 '지구'로 돌아온다.

## 연출 

### 우주선 

- 우주선 레퍼런스 이미지 필요 

### 배경 

- 실사와 같은 화려한 배경 이미지 필요 
- 배경은 처음과 태양계에서는 일반적인 배경이라면 점 차 성운 같은 멋진 연출 필요

### 출항

- 배경이 우에서 좌로 움직이며 우주선이 움직이는 효과
- 우주선 꼬리에 연료(연기) 효과

### 행성 

- 출발은 지구에서 시작하여 태양계의 먼 거리 순서로 행성 표시
- 태양계 밖의 주요 유명한 행성들 정보를 가져올 필요
- 행성마다 단위 필요


## Features
 
### 포커스 인/아웃 감지 

- 포커스 안에있는 상태는 집중
- 포커스 아웃 상태는 실패 

### 집중과 휴식 상태 구분

- 집중 상태에서는 포커스 인/아웃 감지
- 휴식 상태에서는 포커스 인/아웃 감지 안함

### 다른 유저 경쟁 요소 

- 나보다 더 멀리 도달한 유저 숫자 확인
- 현재 위치까지 도달한 유저 보기

### 이동 시간 검증

- 행성 사이 거리를 균일하게 할 것인가 
- 행성 사이 거리를 실제 거리에 비율로 만들 것인가 
  - 우주선의 속도도 지수적으로 커져야 할 수도
